# Framebreak Prototype

Godot 4で制作する、商品レベルの2D対戦格闘ゲームを目指すプロジェクトです。
現在は、ゲームの面白さと操作感を検証するための最初のプレイアブル版です。

## ブラウザで無料プレイ

[Framebreak Prototypeをブラウザで起動](https://hikki0608.github.io/Fighting-game/)

PC版のChromeまたはFirefoxを推奨します。`main` ブランチが更新されると、GitHub Actionsが
GodotのWeb版を自動生成してGitHub Pagesへ公開します。

## 現在遊べる内容

- 1人用CPU対戦（距離、攻撃の隙、ガードを判断するCPU）
- 2人ローカル対戦（キーボード／ゲームパッド）
- トレーニングモード（時間無制限、体力／ゲージ回復、コンボ記録、入力履歴、ダミーガード設定）
- キャラクタービジュアル、光、粒子演出を備えたアニメーション対応モードメニュー
- 通常対戦は「モード選択→ステージ選択→キャラクター選択」、トレーニングは専用ステージ固定で進む画面フロー
- レン／ヴェルのキャラクター選択（1人用はCPUを自動設定、2人用とトレーニングは相手も選択）
- 60fps固定の戦闘シミュレーション
- 歩き、しゃがみ、ジャンプ
- 立ち／しゃがみ通常技、中段、対空、ジャンプ攻撃、投げ
- レンとヴェルで異なる方向別必殺技・空中必殺技・超必殺技
- 攻撃やガードで増加する必殺ゲージと、弱＋強で発動する超必殺技
- 「弱→強→必殺技」を基本とするヒット時キャンセルコンボ
- ジャンプで相手を飛び越えるクロスアップ
- 相手と逆方向＋投げで位置を入れ替える後ろ投げ
- 王門、守護像、城塞の遠景、観客席、金装飾の床を備えた横スクロール／距離連動ズーム対応の王立闘技場
- 中央線・距離目盛り・遠近グリッドを備えた専用トレーニングステージ
- 12fpsの軽量な松明・旗・砂埃アニメーションと、KO／超必殺技に反応する背景演出
- 後ろ入力によるガードと削りダメージ
- スタートアップ／持続／硬直を持つフレーム制の技
- ヒットストップ、画面揺れ、ヒットスパーク
- 99カウント、ラウンド制、KO時の転倒・ダウン保持、タイムアップ、再戦
- F1でヒットボックスとリアルタイムフレーム情報を表示

## ローカルでの起動方法

1. [Godot Engine 4.x](https://godotengine.org/) をインストールします。
2. Godot Project Managerでこのフォルダの `project.godot` をインポートします。
3. `F6` または右上の再生ボタンで起動します。

このプロトタイプは外部アセットやプラグインを必要としません。

## 操作

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| モード選択 | W / S または ↑ / ↓ + Enter | 方向入力 + 決定 |
| ステージ選択 | A / D または ← / → + Enter / Space / J | - |
| キャラクター選択 | A / D または ← / → + Enter / Space / J | - |
| 移動／ガード | A / D | 左スティック |
| ジャンプ／しゃがみ | W / S | 左スティック |
| 弱攻撃 | J | X / □ |
| 強攻撃 | K | Y / △ |
| 必殺技 | L | B / ○ |
| 超必殺技（ゲージ最大） | J + K | X + Y / □ + △ |
| 投げ | I | L1 |
| フレーム情報 | F1 | - |
| トレーニング：位置リセット | Enter | - |
| トレーニング：ダミーガード切替 | T | - |
| トレーニング：コンボ記録消去 | C | - |
| ラウンドリセット | Enter（フレーム情報表示中） | - |
| 再戦 | Enter | - |
| モード選択へ戻る | M / Esc | - |

必殺技は、必殺ボタンと同時に押している方向で変化します。方向は常に相手側を「前」とします。
従来の「下、斜め前、前＋強攻撃」でも前必殺技を発動できます。
ガードは相手と反対方向を押し続けます。下段は下＋後ろ、中段は立ちガードで防ぎます。投げはガードできません。
空中で弱攻撃、強攻撃または必殺ボタンを押すと、専用の空中技になります。
相手と逆方向を押しながら投げると、位置を入れ替えて後方へ吹き飛ばす後ろ投げになります。
1人用ではPlayer 2をCPUが操作します。CPUも人間と同じ入力・技・当たり判定を使用します。
キーボード操作はPlayer 1専用です。2人用対戦のPlayer 2は、2台目のゲームパッドで操作します。
トレーニングでは時間が減らず、両者の必殺ゲージが自動で最大になります。ダミーの体力はコンボ終了後に回復します。
トレーニングでは専用の「TRAINING GRID」が自動選択されます。1人用と2人用では、キャラクター選択の前にステージを選べます。
`T` を押すたび、ダミーガードが「なし→最初の一撃後→常時」の順に切り替わります。

## キャラクター技

### レン：間合いとタイミングを支配する万能型

| 入力 | 技 | 内容 |
|---|---|---|
| 必殺 | 蒼波拳 / AZURE PULSE | 青い衝撃波を飛ばす |
| 前＋必殺 | 瞬閃掌 / FLASH PALM | 高速で踏み込む掌底 |
| 下＋必殺 | 蒼天衝 / SKY BREAK | 発生直後に無敵がある上昇対空 |
| 空中＋必殺 | 流星脚 / COMET DIVE | 斜め下へ急降下する蹴り |
| ゲージ最大＋弱＋強 | 零式・蒼閃連舞 / AZURE ZERO | 高速突進から5連撃を行う超必殺技 |

### ヴェル：接近とガード崩しに特化した攻撃型

| 入力 | 技 | 内容 |
|---|---|---|
| 必殺 | 紅裂爪 / CRIMSON RAKE | 前進しながら3回切り裂く |
| 前＋必殺 | 獣牙跳 / PREDATOR POUNCE | 頭上から襲う中段飛びかかり |
| 下＋必殺 | 狩天爪 / HUNTER RISE | 無敵はないが高威力の上昇対空 |
| 後ろ＋必殺 | 影狩り / SHADOW HUNT | 後退後に急接近し、弱か強へ派生できる |
| 空中＋必殺 | 断頭爪 / REAPER DIVE | 相手をダウンさせる急降下攻撃 |
| ゲージ最大＋弱＋強 | 紅月・獣王裂 / RED ECLIPSE | ガード不能の突進捕獲超必殺技 |

## 設計方針

戦闘員の状態とフレーム進行は `scripts/fighter.gd`、試合ルールとヒット判定は
`scripts/main.gd` に分離しています。キャラクターの名前・色・立ち絵は `CHARACTER_ROSTER` で
管理し、戦闘ロジックを保ったままキャラクターを追加できます。共通通常技とキャラクター固有技は
データとして分離され、飛び道具、複数回ヒット、無敵、ガード属性、ゲージ消費などを技ごとに設定できます。

次のマイルストーンでは、各技の専用アニメーション、効果音、ヒットエフェクト調整、ダウン復帰、
トレーニングメニューを追加します。その後、リプレイと決定論テストを
整備してからロールバック通信へ進みます。
